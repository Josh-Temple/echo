# ECHO

霧に沈む巨大な施設を歩く、横スクロールのブラウザゲームです。低彩度の工業施設、足音、光と影で静かなSFミステリーの雰囲気を描きます。現在は移動と空間表現を体験する短い探索シーンです。

## プレイ

`index.html` をブラウザで開き、「探索を始める」を選びます。画像、フォント、プログラムはHTML内に含まれ、実行時の外部通信、依存ライブラリ、ビルドは不要です。

| 操作 | PC | タッチ画面 |
| --- | --- | --- |
| 移動 | A / D または ← / → | 左側の矢印を押し続ける |
| ジャンプ | Space / W / ↑ | 右側の上矢印 |
| 扉を調べる | E / Enter | 右側の虫眼鏡 |
| 一時停止 | Esc / 右上のメニュー | 右上のメニュー |

地上では加速・減速し、空中では踏み切ったときの横速度を保ちます。足場の切れ目は手前から跳び越えてください。最後の赤い扉まで進み、近づいて調べるとシーンが終わります。

スマートフォンは縦向きと横向きに対応します。横向きでは施設を広く見渡せます。一時停止メニューで、音、描画品質、明るさ、雨と霧の動きを変更できます。ブラウザが対応していれば全画面表示を使えます。

## ビジュアル

- オリジナルのパノラマ背景画。湿ったコンクリート、遠景の霧、工業施設の巨大な構造。
- 遠景、中景、歩く足場、手前の柱が異なる速度で動くパララックス。
- 照明の光束、濡れた足場の反射、接地する影、控えめな雨と浮遊粒子。
- 成人の体格を意識した人物。衣服の立体的な陰影、立ち姿、歩行、踏み切りと着地。
- 探索画面を覆わないUI、静かな開始画面、日本語とタイトル用の内蔵フォント。

Canvas 2Dの描画解像度を端末に合わせます。「自動」では描画が重い状態が続くと解像度と粒子数を抑えます。「軽量」「高画質」も手動で選べます。OSの動きを減らす設定では、雨・霧・浮遊粒子の動きを最初から抑えます。

## 開発

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。GitHub Actionsやパッケージインストールは不要です。

現在の人体アニメーションは簡略化した関節計算による表現です。足音と着地音はWeb Audio APIによる電子合成で、実際の録音ではありません。音はユーザー操作後に再生します。

## 素材

背景画は本プロジェクト向けのオリジナル生成画像です。人物、足場、照明、霧の動きはプログラムで描画しています。参考作品の素材やキャラクターは使用していません。

日本語フォントは [Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp) の必要な文字を抜き出し、HTMLに含めています。フォントの [SIL Open Font License](docs/OFL-NotoSansJP.txt) はHTML内にも同梱しています。
